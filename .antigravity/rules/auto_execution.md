# Autonomous Auto-Execution Rule

- **Auto-Execution Enabled**: Always execute implementation plans, code edits, terminal commands, builds, and verifications automatically.
- **No Blocking Approvals**: Do not pause, block, or wait for explicit manual user approval before starting file edits, code modifications, or terminal build commands.
- **End-to-End Autonomous Workflow**: Automatically perform complete end-to-end research, implementation, compilation, testing, and deployment to main branch.
